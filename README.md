# Time Village Website

A responsive, single-page corporate website for Time Village and Resorts Private Limited.

## Included
- `index.html` — website content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — project visuals plus the supplied original Time Village clock logo used in the header, footer and browser tab

## Publish using GitHub Pages
1. Create a GitHub repository, for example `time-village-website`.
2. Extract this ZIP file on your computer.
3. Upload the contents of the extracted folder to the **root** of your repository. Keep the `assets` folder and its images together.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The URL will appear in Settings → Pages.
